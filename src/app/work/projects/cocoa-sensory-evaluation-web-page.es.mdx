## Resumen

Una página web diseñada para apoyar la evaluación sensorial humana de muestras de licor de cacao y presentar resultados mediante gráficos radar.

## Funcionalidades

- Recolección estructurada de datos sensoriales mediante formularios.
- Generación de gráficos radar para comparar perfiles.
- Visualización clara de fortalezas y diferencias sensoriales entre muestras.
